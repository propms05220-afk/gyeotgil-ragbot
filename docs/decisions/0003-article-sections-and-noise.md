# 0003 — 섹션 = 법령 약칭, 하위 섹션 = 조문; 코어에 잡음 블록 훅 추가

**상태:** 채택 · 2026-10-29

## 배경
kordoc 기본 규칙(level 1 heading = 섹션)으로는 세 문서 모두 섹션이 잡히지 않았다.
- 법률·시행령의 heading 은 맨 위 법령 이름 하나(level 3)뿐이고, 조문 `제11조(자기돌봄비) …` 는 일반 문단이다.
  → 전부 `(front matter)` 한 섹션이 되어 청크에 "몇 조인지, 법률인지 시행령인지" 맥락이 없었다.
- 보도자료는 heading 이 0개.
- 법령 로고를 OCR 한 `HE i`, `L -L F`, `모E:` 와 보도자료 체계도 조각 글자, 빈 표가 그대로 청크가 될 상황이었다.
  기존 `SectionRules` 에는 블록을 버리는 방법이 없었다.

## 결정
- `src/ragbot/domain/sections.py`: 법령 heading → 약칭 섹션, `제N조(…)` → 하위 섹션(제목/본문 분리), `제N장` → 끊기만,
  보도자료 1행 표(`보도자료`, `붙임N`) → 섹션, `□ (…)` → 하위 섹션, `is_noise` 로 OCR 잔해와 빈 표 제거.
  자세한 규칙과 이유: `docs/DATA.md` 1절 "섹션 규칙".
- 코어 `src/ragbot/ingest/sections.py`: `SectionRules` 에 선택 필드 `is_noise(block) -> bool` (기본값: 아무것도 안 버림)을
  추가하고 `build_sections` 가 이미지와 함께 건너뛴다. 도메인 단어 없음, 기존 프로젝트 동작 그대로.
- `tests/test_domain.py`: 섹션 테스트 2개를 실제 값으로 채우고 잡음 테스트 1개 추가.
  `tests/test_core_is_domain_free.py`: 도메인 단어 7개 추가.

## 대안
- 장(`제N장`)을 섹션으로: 경로가 2단계뿐이라 법령 이름이 빠지고, 법률 제1조와 시행령 제1조가 구분되지 않아 하지 않음.
- 꺾쇠 캡션 `< … >` 을 하위 섹션으로: 표 뒤의 본문까지 캡션 아래로 들어가 잘못된 breadcrumb 이 생겨 하지 않음.
- 잡음을 `section_title`/`is_subsection` 로 우회: 잡음이 하위 섹션 이름이 되어 더 나빠져서 코어 훅을 택함.
