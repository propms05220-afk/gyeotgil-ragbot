# 코어 설계 결정 (원본 프로젝트에서 가져옴, 참고용)

이 폴더의 기록은 `rag_chatbot_starter`(CBNU 유학생 도우미)를 만들며 내린, **코어 동작**에 관한 결정입니다.
이 템플릿의 코어가 왜 이렇게 동작하는지 설명하므로 그대로 둡니다. 예시와 수치는 CBNU 데이터 기준입니다.

| 기록 | 코어의 어디에 있나 |
|---|---|
| 0004 도구 없는 답은 되돌려 보낸다 | `agent.py` 가드레일 1 |
| 0005 "찾을 수 없음" 전에 웹(과 나머지 소스)을 찾는다 | `agent.py` 가드레일 2 |
| 0006 검색 전에 소스를 정한다 (라우터 + 소스 카드) | `router.py`, `config.yaml → sources` |
| 0007 코어와 도메인을 나눈다 | `src/ragbot/domain/`, `tests/test_core_is_domain_free.py` |

여러분의 결정은 한 단계 위 `docs/decisions/` 에 `0001-…` 부터 새로 씁니다 (`0000-template.md` 참고).
