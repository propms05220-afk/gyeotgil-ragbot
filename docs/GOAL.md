# 목표 — 곁길 지원제도 안내 챗봇

> 2026-10-29 초안. 결정(지역 범위, 사용자, 안내처, 목표 수치)은 팀이 정했고 문장은 코딩 에이전트가 정리했다.
> "사용자가 실제로 묻는 질문" 은 아직 **후보**다. 실제 사용자 질문으로 바꾸기 전까지 tasks/01 은 완료가 아니다.

## 문제

13~34세 가족돌봄청년은 아픈 가족을 돌보느라 학업과 일을 놓치지만, 자신이 지원 대상인지조차 모르는 경우가 많다
(경기도 가족돌봄청년 조사: 사회복지 서비스를 한 번도 이용해 본 적 없음 48.6%, 곁길 기획서 인용).
2026년 3월 26일 「가족돌봄 등 위기아동ㆍ청년 지원에 관한 법률」이 시행되며 제도가 바뀌었지만, 근거는 법률·시행령·보도자료에
흩어져 있고, 언론은 자기돌봄비를 "연 200만 원" 과 "1회 200만 원" 으로 엇갈리게 쓴다. 지금은 검색하거나 구청·청년미래센터에
직접 물어봐야 한다.

## 사용자

- **주 사용자:** 13~34세 가족돌봄 아동·청년 (전국). 한국어 사용. 가족을 돌보고 있다는 건 알지만 "가족돌봄청년" 이라는 말,
  지원 대상 요건, 어디에 신청하는지는 모른다. 청소년부터 직장인까지 있어 쉬운 말로 답해야 한다.
- **보조 사용자:** 청년미래센터 상담사, 대학 학생상담센터 직원 (답을 검토하고 상담 전 안내에 쓴다).

## 챗봇이 해야 할 일

1. **문서**(위기아동청년법·시행령, 보건복지부 2026.3 보도자료)에서 지원 대상 요건, 자기돌봄비 기준·금액·신청처·지급 방식,
   지원 종류, 나이별 담당 기관 질문에 답한다. 출처(문서, 페이지)를 밝힌다.
2. 문서가 다루지 않는 질문은 **웹**에서, 공식 사이트(law.go.kr, mohw.go.kr, korea.kr, bokjiro.go.kr)를 우선하고 그렇다고 밝힌다.
3. 한국어로 답한다 (ko).
4. 자격은 "조건에 맞아 보인다 / 맞지 않아 보인다" 까지만 말하고, 최종 판단은 신청 창구가 한다고 덧붙인다.
5. 어떤 소스에도 답이 없으면 "찾을 수 없다" 고 말하고 보건복지상담센터(129) 또는 청년미래센터·거주지 구청을 안내한다. 추측하지 않는다.

## 사용자가 실제로 묻는 질문 (10개 이상)

**후보 — 실제 질문으로 확인 필요.** 곁길 기획서의 페르소나 인용과 지금까지의 자료 조사에서 뽑았다. 영케어러 인터뷰,
대학 커뮤니티, 지식iN, 청년미래센터·복지로 FAQ 에서 실제로 나온 질문으로 바꾸거나 확인하고, 출처를 옆에 적는다
(개인을 알아볼 수 있는 정보는 지운다).

1. 엄마 병원 동행 때문에 수업을 자주 빠지는데, 저도 가족돌봄청년 지원을 받을 수 있나요?
2. 자기돌봄비는 얼마이고, 매년 받을 수 있나요?
3. 자기돌봄비는 어디에 신청하나요?
4. 자기돌봄비는 현금으로 들어오나요?
5. 군대를 다녀와서 지금 35살인데 신청할 수 있나요?
6. 아버지랑 주소가 다른데 돌봄을 하고 있으면 대상이 되나요?
7. 집에 형(38세)이 같이 사는데 제가 주로 돌보면 대상인가요?
8. 소득 기준이 부모님 소득인가요, 제 소득인가요?
9. 12살 동생이 할머니를 돌보는데 어디에 도움을 요청하나요?
10. 청년미래센터에서는 무엇을 도와주나요?
11. 신청할 때 어떤 서류가 필요한가요? (문서에 없음 → "찾을 수 없음")
12. 서울시 자기돌봄비랑 같은 건가요? (범위 밖)

## 성공 목표 (`eval/thresholds.yaml` 로 강제)

| 지표 | 목표 |
|---|---|
| `eval/golden_qa.jsonl` 정답률 (accuracy) | ≥ 0.80 |
| 소스 정확도 (route_accuracy: 맞는 소스를 썼는가) | ≥ 0.85 |
| 문서(docs) 소스 정답률 | ≥ 0.80 |
| 답할 수 없는 질문에 "찾을 수 없음" | 전부 |

지원 제도 안내는 틀리면 사용자가 받을 수 있는 지원을 놓친다. 그래서 정답률 기준을 템플릿 기본(0.75)보다 높게 잡았고,
모르는 것을 지어내지 않는 것을 정답률보다 우선한다.

## 범위 밖

| 하지 않는 것 | 이유 | 대신 하는 것 |
|---|---|---|
| 최종 자격 판정 | 지원대상자 선정은 청년미래센터(법 제13조), 자기돌봄비 지급 결정은 시장·군수·구청장(시행령 제11조) 이 한다 | 요건을 설명하고 청년미래센터·거주지 구청 안내 |
| 대신 신청하기, 개인 기록 조회 | 개인정보와 건강 정보를 다루지 않는다 | 신청 창구 안내 |
| 심리 상담 | 챗봇은 상담을 대신하지 않는다 | 위기 신호(자해, 극단적 생각)가 보이면 자살예방상담전화 109 를 먼저 안내 |
| 일자리·수업 추천 | 곁길의 다른 기능이고 이 챗봇의 자료에 없다 | "이 챗봇은 지원 제도만 안내한다" 고 말함 |
| 지역 자체 사업 (예: 서울시 자기돌봄비) | 국가 사업과 이름이 같아 섞이기 쉽고, 자료가 없다 | 거주지 구청 또는 129 안내 |
| 문서에 없는 세부 기준 (신청 서류, 중위소득 금액 등) | 시행규칙·고시·사업안내를 아직 구하지 못했다 | "찾을 수 없음" + 129 또는 청년미래센터 안내 |
